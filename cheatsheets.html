Prompts para trabajar con código con IA

La diferencia entre un buen resultado y uno inútil casi nunca es el modelo: es si le das contexto suficiente y le pides que no invente.

ParaEscribe esto
Entender código"Explica qué hace este archivo sección a sección. No propongas cambios todavía."
Encontrar un error"Este es el error y el código. Dime la causa más probable antes de proponer un arreglo, y dime cómo comprobarla."
Escribir un test"Escribe el test para este caso límite. Si el test no detecta el fallo, no lo escribas."
Refactorizar"Refactoriza esto en pasos pequeños, uno por mensaje. No cambies el comportamiento."
Rastrear un bug"Actúa de revisor escéptico: qué suposiciones no verificadas hay aquí?"
Desbloquearte"Dame 3 enfoques distintos con su peor caso. No me digas cuál elijas."

Las tres reglas que más importan: dale el error entero, pide que no invente y pide un paso cada vez. Pedir diez cambios de golpe es la forma más rápida de acabar con código que no entiendes.

Git: lo que usas el 90% del tiempo
ParaComando
Ver qué has cambiadogit status
Preparar y confirmargit add . && git commit -m "mensaje"
Ver el historial resumidogit log --oneline --graph
Crear rama y cambiargit checkout -b mi-rama
Subir cambiosgit push -u origin mi-rama
Traer cambios remotosgit pull --rebase
Deshacer el último commitgit commit --amend
Ver qué cambió, línea a líneagit diff
Descartar cambios localesgit restore .

Dos reglas que te ahorran problemas: haz commit pequeño y seguido (es tu punto de vuelta si la IA te rompe el código), y antes de git pull en un trabajo con cambios usa siempre --rebase para no crear un merge commit por accidente.

Docker para desarrollo
ParaComando
Construir la imagendocker build -t mi-app .
Arrancar un contenedordocker run -it --rm -p 3000:3000 mi-app
Levantar todo con un archivodocker compose up -d
Ver los contenedores vivosdocker ps
Ver los logsdocker compose logs -f
Parar y borrardocker compose down

Para desarrollo, lo normal es no construir la imagen a mano: pones tu código en un volumen, lanzas la imagen y el proceso de recarga hace el resto.

Regex: las que más se usan
ParaPatrón
Dígitos\d+
Palabras\w+
Cualquier carácter.
Inicio de línea^
Fin de línea$
Uno u otro (espacios)\s+
Grupo opcional(...)?
Uno de varios[abc]
Uno de varios (excluido)[^abc]
Cadena de correo[\w.+-]+@[\w-]+\.[\w.]+

En JavaScript usa siempre la bandera g para reemplazar todas las apariciones: texto.replace(/x/g, "y"). Y recuerda que . no salta de línea: usa [\s\S] o la bandera s cuando necesites que sí.
