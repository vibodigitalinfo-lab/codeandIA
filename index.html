Lo que uso

Las herramientas que uso de verdad y que recomendaría a quien está aprendiendo a programar con IA. Cada una con su review si la he analizado a fondo.

Cursor

Editor IA

Editor basado en VS Code con IA integrada en toda la experiencia: chat contextual, refactor con Ctrl+K y autocompletado que entiende tu proyecto entero.

Probar → Review Cursor Guía .mdc

GitHub Copilot

Asistente

El asistente de IA de GitHub que vive dentro de tu editor favorito. Gratis para estudiantes verificados con el Student Pack. Ahora con Agent Mode autónomo.

Probar → Review Copilot Guía Agent Mode

ChatGPT

Chat IA

El chatbot de referencia para depurar, entender errores y mantener conversaciones largas con contexto. Ideal para el día a día de desarrollo.

Probar → Review ChatGPT Plus Guía JS con IA

Claude Code

CLI Agente

Agente autónomo en terminal: lee el repo entero, edita varios archivos, ejecuta tests y lanza sub-agentes paralelos (Dynamic Workflows). Para tareas senior.

Probar → Review Claude Code

Warp

Terminal IA

Terminal reescrita en Rust con bloques, IA integrada (Warp Agent), editor LSP y compartir sesión en un clic. Multiplataforma nativa (Mac/Linux/Win).

Probar → Review Warp

v0 by Vercel

Generación UI

Genera interfaces React + Next.js + Tailwind + shadcn/ui desde lenguaje natural. GitHub sync nativo, deploy en Vercel con un clic, MCP integrations.

Probar → Lista + comparativa

Hostinger

Hosting

Hosting barato y rápido para poner en marcha tus proyectos y tu portafolio sin complicarte. hPanel intuitivo, SSH, LiteSpeed.

Probar → Review Hostinger

Namecheap

Dominios

Dominios a buen precio y sin sorpresas raras en la renovación. La opción que uso para registrar dominios.

Probar → Comparativa Namecheap vs Porkbun

CodeRabbit

Code Review IA

Revisa pull requests automáticamente con IA: detecta bugs, seguridad, rendimiento y sugiere fixes. Gratis para repos públicos, multi-plataforma (GH, GL, Azure, BB).

Probar → Review CodeRabbit

Qodo (ex-Codium)

Testing IA

Genera tests unitarios en tu IDE (VS Code, JetBrains) y PR-Agent open source para reviews automáticas en GitHub/GitLab. Trial de 14 días.

Probar → Comparativa QA Wolf vs Qodo

Cómo pruebo cada herramienta

No escribo de oídas. Cada herramienta que aparece por aquí la he usado yo, en mi día a día como estudiante, durante semanas. Este es mi método:

  1. La uso de verdad en proyectos reales de clase o personales, no en un tutorial de cinco minutos.
  2. Mido lo que importa: velocidad, límites, precio real y si te hace mejor programador o solo más rápido.
  3. Actualizo cuando cambia algo importante: precios, planes o funciones nuevas.
  4. También cuento lo malo. Nada de reviews pagadas: si algo no me convence, lo digo.

Algunos enlaces son de afiliado: si compras a través de ellos, me llevo una pequeña comisión sin coste extra para ti. Eso mantiene el blog gratis y en ningún caso condiciona mi opinión.

Preguntas frecuentes

¿Cuál es la mejor IA para programar siendo principiante?

Si empiezas, te recomiendo Cursor: su chat contextual te ayuda a entender tu propio código, no solo a autocompletar. Y si eres estudiante, GitHub Copilot gratis con el Student Pack es un gran punto de partida. Depende de si prefieres un editor completo o un asistente dentro del tuyo.

¿Hay herramientas de IA gratis para estudiantes?

Sí. GitHub Copilot es gratis con el Student Developer Pack. Cursor tiene un plan gratuito con un límite mensual de peticiones que da bastante de sí. Y ChatGPT tiene una versión gratuita, aunque con límites de mensajes.

¿Merece la pena pagar ChatGPT Plus?

Depende de cuánto lo uses. Si trabajas a diario con contexto largo o te quedas sin mensajes en los peores momentos, puede valer la pena. Te lo cuento con detalle en mi análisis de ChatGPT Plus.

¿Qué son los enlaces de afiliado?

Son enlaces por los que, si compras, el blog recibe una pequeña comisión sin coste adicional para ti. Solo recomiendo herramientas que he probado yo mismo, y la presencia de un enlace de afiliado nunca cambia mi opinión.
